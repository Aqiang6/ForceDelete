### ForceDelete 强制删除工具 README

#### 📌 项目简介

`ForceDelete.bat` 是一个轻量级 Windows 批处理脚本，专为快速、彻底地清除顽固文件/文件夹而设计。只需将目标拖拽至脚本图标上即可执行强制删除，无需打开命令行手动输入路径。

> ⚠️ **高危操作警告** 本工具执行的是**不可逆的物理删除**，文件不会进入回收站，且无法通过常规数据恢复软件还原。请务必在确认目标无误后使用，作者不对任何误删导致的数据丢失承担责任。

#### ✨ 功能特性

- **拖拽即用**：支持单个或多个文件/文件夹拖入批量处理
- **智能识别**：自动区分文件与文件夹，调用对应的删除命令
- **强力清除**：可删除只读、隐藏、系统属性文件及非空目录
- **安全防呆**：双击空跑时自动拦截并提示，防止误触
- **结果反馈**：逐项显示删除状态（成功/失败/跳过）
- **中文兼容**：原生支持 GBK 编码，完美处理中文路径

#### 🚀 使用方法

1. 将 `ForceDelete.bat` 保存到任意固定位置（如桌面或工具栏）
2. 选中需要删除的一个或多个文件/文件夹
3. 将其直接拖拽到 `ForceDelete.bat` 图标上释放
4. 等待命令行窗口显示处理结果，按任意键关闭

#### ⚙️ 技术说明

| 参数           | 作用                               |
| :------------- | :--------------------------------- |
| `del /f /q /a` | 强制静默删除所有属性文件           |
| `rd /s /q`     | 强制静默递归删除整个目录树         |
| `shift + goto` | 循环遍历所有拖入的参数             |
| `chcp 936`     | 确保 CMD 代码页与脚本 GBK 编码一致 |

#### 📋 编码注意事项

- **必须保存为 ANSI (GBK) 编码**，UTF-8 编码会导致中文路径识别失败
- 记事本另存为时选择 "ANSI"；Notepad++ 选择 "GB2312"
- 若修改后出现乱码，请用对应编辑器重新以 GBK 编码保存

#### ❓ 常见问题

**Q: 提示“删除未成功”怎么办？** A: 通常是因为文件被进程占用或当前用户权限不足。请先关闭占用该文件的程序，或以管理员身份运行脚本（右键 → 以管理员身份运行）。

**Q: 能否撤销删除？** A: **不能**。本工具绕过回收站直接擦除数据，请在操作前做好备份或二次确认。

**Q: 拖入后闪退没有反应？** A: 检查脚本编码是否为 GBK。用记事本打开脚本，若中文显示乱码，则说明编码错误，请重新以 ANSI 编码保存。
